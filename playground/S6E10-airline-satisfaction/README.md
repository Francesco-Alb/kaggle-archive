# Kaggle Playground Series - Season 6, Episode 10: Airline Satisfaction Prediction

The objective of this challenge is to predict passenger satisfaction (`satisfaction`).

---

## Challenge Overview

- **Competition:** Kaggle Playground Series S6E10 (`playground-series-s6e10`)
- **Task:** Binary Classification
- **Target Variable:** `satisfaction` (Values: probabilities between 0 and 1)
- **Evaluation Metric:** [Area Under the ROC Curve (ROC AUC)](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.roc_auc_score.html)

### Submission Format
For each `id` in the test set, you must predict a probability for the `satisfaction` variable. The submission file should look like this:
```csv
id,satisfaction
699635,0.2
699636,0.3
699637,0.1
etc.
```
